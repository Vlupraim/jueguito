# Iteraciones del kit de HUD

Esta carpeta es un archivo de exploracion, no una papelera. Las variantes se conservan porque pueden convertirse en rangos, facciones, mejoras o estados especiales.

- `portrait_frame_ornate_rank_concept_v1.png`: demasiado dominante para nivel base; candidato a marco de rango alto o logro.
- `portrait_frame_minimal_chroma_v1.png`: base aprobada para el retrato inicial.
- `action_slot_chroma_v1.png`: ranura neutral; sus muescas son detalle ambiental, no informacion.
- `minimap_frame_chroma_v1.png`: variante metalica limpia, candidata a interfaz naval o evolucion.
- `minimap_frame_parchment_chroma_v2.png`: variante base aprobada para el minimapa.
- `resource_bar_chroma_v1.png`: marco compartido aprobado para recursos.
- `pause_panel_chroma_v1.png`: panel base aprobado por su espacio negativo.
- `menu_button_chroma_v1.png`: boton base aprobado; los estados se resuelven mediante valor, contorno y simbolo.
- `map_screen_frame_chroma_v1.png`: marco exterior aprobado para `Tab` y `M`; el contenido permanece completamente dinamico.
- `map_viewport_frame_chroma_v1.png`: marco interior de pergamino aprobado para separar el mapa de los controles.
- `map_menu_shell_chroma_v1.png`: carcasa unificada del mapa regional; integra cabecera, pie, marco del mapa y columna lateral sin contenido ficticio.
- `world_atlas_shell_chroma_v1.png`: variante exclusiva del atlas; elimina la columna fija y entrega casi todo el espacio a la carta mundial.
- `implemented_map_regional_v1.png` y `implemented_world_atlas_v1.png`: primera comprobacion dentro del juego; revelo pestañas de cabecera sobredimensionadas.
- `implemented_map_regional_v2.png` y `implemented_world_atlas_v2.png`: comprobacion final con pestañas compactas, carcasas diferenciadas y ficha territorial superpuesta.
